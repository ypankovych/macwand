Millions of files in seconds

The scanner is written in Rust and walks your folders on every core at once. Findings stream into the window as they're found, so you can start reviewing before the scan is done.

Knows where developers lose space

Dependency folders and build output pile up in every project you've ever cloned. MacWand finds them and lists them by project, so you can clear the ones you're not working on. They come back with the next install or build.

  • Rust target
  • Python virtualenvs

  • iOS device support
  • npm · pnpm · Cargo
  • Gradle · Maven · Go
  • pip · uv

Uninstall the whole app, not just the icon

Dragging an app to the Trash leaves its data behind. MacWand finds the support files each app keeps in your Library and removes them along with it. It also shows when you last used each app, so the forgotten ones stand out.

Nothing goes without your say-so

Every removal is confirmed and goes to the Trash, where you can put it back. Each section says whether it's safe to remove or worth a look first, and apps that are running are never touched. The scanner itself can't delete anything.

  • Safe to remove: caches, logs, build folders, Xcode data
  • Review first: large files, Downloads, backups, archives

Counts the space files really use

MacWand measures the blocks a file actually takes on disk, not the size it claims. Sparse disk images, files that live only in iCloud and hard links don't inflate the totals, so what it says you'll free is what you'll free.

Install in a minute

  1. Download

    Get the latest DMG from GitHub releases.

  2. Drag to Applications

    Open the DMG and drag MacWand into your Applications folder.

  3. Open it once

    MacWand isn't notarized by Apple yet. The first time, open it, then go to System Settings › Privacy & Security and click Open Anyway. On macOS 14 and earlier, right-click the app and choose Open.

For a complete scan, allow MacWand under Privacy & Security › Full Disk Access. Without it, macOS hides Mail, Safari and other apps' data from the scan.
